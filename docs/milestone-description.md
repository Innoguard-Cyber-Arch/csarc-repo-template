# Story Milestone description

```markdown
## Problem

Who is affected and what end-to-end gap remains?

## Outcome

What observable result makes this story complete?

## Acceptance criteria

- [ ] List story-level checks, not implementation tasks.

## Out of scope

What related work is intentionally excluded?

## Verification

How will a maintainer verify the complete outcome?

## Source

Link the approved spec, plan, user story, or adoption audit.
```

Attach only Issues that directly advance these criteria. Do not attach their
pull requests as duplicate progress items. Use a due date only for a real
deadline, not as a release label.
